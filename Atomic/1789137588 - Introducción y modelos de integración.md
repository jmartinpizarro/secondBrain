## Modelos de integración

1. **Interoperabilidad** - capacidad de distintos sistemas para intercambiar datos e interactuar entre sí
2. **Flujo de datos** - establecimiento de flujos de datos es uno de los aspectos centrales de la integración
3. **Middleware** - se utiliza a menuda en la integración de sistemas
4. **API** - permiten a diferentes aplicaciones de software comunicarse entre sí
5. **Transformación de datos** - pueden utilizar formatos o estructuras de datos diferentes
6. **Seguridad y autenticación** - garantizar la seguridad de los datos y los sistemas es fundamental para la integración
7. **Tratamiento de errores** 
8. **Logs**
